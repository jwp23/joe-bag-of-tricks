# future-skills

A parking lot for skills rescued from other machines or authored elsewhere, held here
verbatim until they are reviewed and promoted into a plugin.

Nothing in this directory ships. It sits outside every plugin root, so `claude plugin
validate`, `verify-skills-load.sh`, and the context-budget gate do not see it, and no
session loads it.

Promoting one is a deliberate act: rework it through
`/joe-bag-of-tricks:writing-skills`, move it under the target plugin's `skills/`, and
delete it from here.
